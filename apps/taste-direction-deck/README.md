# Taste Direction Deck

One screen that deals three [Taste Skill v2](https://github.com/Leonxlnx/taste-skill) art directions for a short brief, previews each palette, type pairing, and hero, and copies a `DESIGN.md` snippet.

```bash
bun install
bun run dev
```

The direction library is vendored under `vendor/taste-skill/` (MIT, Copyright (c) 2026 Leonxlnx). See `vendor/taste-skill/SOURCE.md`.

`bun test` checks the dealer against known `draw.mjs` seeds.
